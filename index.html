Fundamentos de Programación

Lo básico sobre Python

Python es un lenguaje interpretado, de tipado dinámico y alto nivel, diseñado para que el código sea claro y expresivo. Todo programa, sin importar su complejidad, se construye sobre tres pilares fundamentales: cómo se representa la información, cómo se transforma y cómo se comunica con el exterior.

Los tipos de datos definen la naturaleza de la información que maneja un programa: números enteros o decimales para cálculos, cadenas de texto para comunicar, y valores booleanos para tomar decisiones. Python infiere el tipo automáticamente, pero conocerlo es esencial para operar con precisión.

Los operadores son los instrumentos que permiten transformar esa información: realizan cálculos aritméticos, comparan valores, combinan condiciones lógicas y manipulan datos a nivel de bits. Cuando se combinan varios operadores en una misma expresión, la precedencia determina el orden en que Python los evalúa.

Finalmente, todo programa útil necesita interactuar con el mundo: recibir datos del usuario con input() y mostrar resultados con print(). Dominar la entrada y salida, junto con las f-strings, permite presentar información de forma clara, formateada y profesional.

Estos elementos, sumados a las sentencias de asignación, forman el vocabulario básico con el que se construye cualquier programa en Python.

💡 Dato importante

La diferencia fundamental con C: Python es de tipado dinámico. No declaras el tipo de una variable, Python lo infiere en tiempo de ejecución. No hay int x = 5; — solo x = 5.

Comentarios y documentación básica

Cómo anotar y documentar el código en Python

💬 ¿Qué es un comentario?

Un comentario es texto que Python ignora completamente durante la ejecución. Sirve para explicar qué hace el código, por qué se tomó una decisión o para desactivar líneas temporalmente. Un código bien comentado se entiende meses después sin releerlo entero.

💡 Regla de oro

Si el código es claro, no necesita un comentario que repita lo obvio:
# suma a y b junto a a + b, no aporta nada.

# Comentario de una línea

Se inicia con el símbolo #. Todo lo que sigue en esa línea es ignorado por el intérprete.

Python ejemplo 
# Este programa calcula el área de un círculo
PI = 3.14159             # constante matemática
radio = 5
area = PI * radio ** 2   # fórmula: π·r²
print(area)              # 78.53975
salida 
78.53975

💬 Comentario de varias líneas

Python no tiene una sintaxis especial para comentarios multilínea. La convención es usar varias líneas con #, o bien una cadena de texto entre comillas triples """...""" que no se asigna a ninguna variable (Python la evalúa y la descarta).

Python ejemplo 
# Opción A: varias líneas con #
# Este bloque convierte temperatura
# de Celsius a Fahrenheit.
celsius = 100
fahrenheit = celsius * 9/5 + 32
print(fahrenheit)   # 212.0

# Opción B: cadena multilínea (no asignada)
"""
Este bloque también es ignorado.
Se usa cuando el comentario es muy largo
o contiene formato especial.
"""
print("Listo")
salida 
212.0
Listo
📝 Nota:

Las cadenas """...""" no son comentarios reales: son objetos de tipo str que se crean y se descartan. En la práctica se comportan como comentarios, pero si aparecen justo después de una función (def) o una clase (class), Python las trata como docstrings (documentación formal), no como comentarios.

📝 Nota:

En teoría formal de lenguajes de programación, = (y sus variantes +=, -=, etc.) es una sentencia de asignación (assignment statement), no una expresión que devuelve un valor utilizable. Por eso en Python no puedes hacer esto:


Python sintaxis 
print(x = 5)  # ❌ Error

Si = fuera un operador normal (como +), podrías usarlo dentro de una expresión y obtener un valor de vuelta, pero no es así. Su función es ejecutar una acción (asignar), no producir un valor para usar en otra expresión.

Por convención y por practicidad en la enseñanza, se les agrupa dentro de "operadores", aunque se reconoce que técnicamente no forman una expresión, sino una sentencia.

⬅️ Tipos principales de asignación

Para el operador de asignación = existen diversas variaciones de esta sentencia en Python:

Es la más común, vinculando un valor único a una variable única.
Ejemplo:

B. Asignación Múltiple
Permite inicializar varias variables con el mismo objeto en una sola línea.
Ejemplo:
base = altura = profundidad = 0
Equivale a:
base = 0
altura = 0
profundidad = 0

C. Asignación Empaquetada (Unpacking)
Permite asignar múltiples valores a múltiples variables simultáneamente basándose en una estructura iterable.
Ejemplo:
x, y, z = 10, 20, 30
Equivale a:
x = 10
y = 20
z = 30

La función input()

Lee datos desde el teclado

input() es la función que se usa para pedirle datos al usuario desde el teclado mientras el programa se está ejecutando. Detiene el programa, espera a que el usuario escriba algo y presione Enter, y devuelve lo escrito siempre como texto (string).

📖 Sintaxis:

Python sintaxis 
variable = input(mensaje_opcional)

donde:

  • mensaje_opcional: un texto (string) que se muestra como aviso o pregunta antes de que el usuario escriba. Es opcional.
  • El valor que el usuario ingresa se guarda en variable, y siempre es de tipo str, sin importar lo que se escriba.

⚠️ Precaución:

🔥 input() SIEMPRE devuelve una cadena (str). Aunque el usuario escriba números.

💻 Ejemplo:

Python ejemplo 
nombre = input("Nombre: ")

🔄 Conversión de tipos

Como input() siempre devuelve una cadena (str), normalmente se convierte.

📖 Sintaxis

Python sintaxis 
variable = tipo(input())

donde:

  • input(): siempre devuelve una cadena (str).
  • tipo: puede ser int, float, complex, etc.

💻 Ejemplo: Lee múltiples valores del mismo tipo de dato en una línea

Python ejemplo 
# Entrada: "3 7"
a, b = map(int, input("Ingresa dos números enteros: ").split())
# a=3, b=7
print(a)
print(b)
salida 
3
7

El método split() toma una cadena de texto y la divide en trozos más pequeños usando un separador (por defecto, los espacios en blanco). Toma la cadena "3 7", la divide por el espacio en blanco y obtiene "3" y "7" (siguen siendo texto).

La función map() toma un tipo de dato o función de conversión (en este caso int) y se lo aplica automáticamente a cada uno de los elementos divididos por split(). Convierte "3" y "7" a enteros 3 y 7.

Al combinar split(), map() y desempaquetado de variables, puedes leer múltiples variables convertidas en una sola línea. Finalmente tenemos: a = 3 y b = 7.

La función print()

Envía información a la consola

print() s la función que se usa para mostrar información en la pantalla (salida estándar). Es una de las funciones más usadas para ver resultados, mensajes o depurar código..

📖 Sintaxis:

Python sintaxis 
print(objeto1, objeto2, ..., objeto_n, sep=' ', end='\n', file=sys.stdout, flush=False)

donde:

  • objeto1, objeto2, ..., objeto_n: uno o más valores a mostrar (pueden ser strings, números, variables, expresiones, etc.). Se separan por comas.
  • sep: el separador entre los objetos (por defecto es un espacio ' ').
  • end: lo qué se agrega al final (por defecto es un salto de línea '\n').
  • file: a dónde se envía la salida (por defecto la consola).
  • flush: si se fuerza a vaciar el buffer inmediatamente (por defecto False).

📖 Formateo de cadenas antes de Python 3.6

En las versiones de Python anteriores a la version 3.6, se utilizaban principalmente tres formas para insertar valores dentro de cadenas de texto: la concatenación con +, el operador % y el método .format().

La concatenación fue la forma más básica y sencilla. Consistía en unir cadenas manualmente, aunque tenía la desventaja de requerir conversiones explícitas con str() cuando se trabajaba con números u otros tipos de datos.

Posteriormente se popularizó el operador % (Python 1) , heredado del estilo de lenguaje C. Permitía insertar valores mediante especificadores de formato y durante muchos años fue el método más utilizado en Python clásico.

Más adelante apareció el método .format() (Python 2.6) , diseñado para ofrecer una sintaxis más flexible y legible que %. Este método permitió controlar posiciones, nombres y formatos de salida de manera más cómoda, convirtiéndose en el estándar antes de la llegada de las f-strings.

Actualmente, las f-strings son la opción recomendada porque hacen el código más claro, más fácil de escribir y generalmente más eficiente.

📖 f-strings (Python 3.6+)

Las f-strings (formatted string literals) son una forma moderna de insertar valores y expresiones dentro de cadenas en Python. Fueron introducidas en Python 3.6 y actualmente son el método recomendado para formatear texto.

La idea principal es colocar una f antes de las comillas de la cadena. Después, cualquier expresión escrita entre llaves {} será evaluada e insertada automáticamente dentro del texto.

📖 Sintaxis:

Python sintaxis 
f"texto {expresion} texto"
o
f'texto {expresion} texto'

💻 Ejemplo:

Python ejemplo 
nombre = "Ana"
edad = 25
print(f"Me llamo {nombre} y tengo {edad} años")
salida 
Me llamo Ana y tengo 25 años

Los {} pueden contener cualquier expresión válida en Python, como variables, operaciones, funciones y especificadores de formato.

💻 Ejemplo:

Python ejemplo 
# Variables y operaciones
x = 5
y = 7
print(f"La suma de {x} y {y} es {x + y}")

# Funciones
usuario = "ana lópez"
print(f"Hola, {usuario.upper()}")

# Concatenar cadenas
nombre = "Juan"
apellido = "Pérez"
texto = f"Nombre: {nombre}, " + f"Apellido: {apellido}"
print(texto)
salida 
La suma de 5 y 7 es 12
Ana López
Nombre: Juan, Apellido: Pérez

Python ejemplo 
nombre = "Ana"

Son especialmente útiles para generar mensajes largos, reportes o bloques de texto formateado.

f-strings: Específicadores de Formato

Controla el ancho, alineación, precisión y tipo de los valores al mostrarlos con f-strings

📖 Especificadores de formato

Dentro de los {} puedes usar : seguido de un especificador de formato para controlar cómo se muestra el valor. La sintaxis es:

📖 Sintaxis:

Python sintaxis 
f"{expresión : especificador}"

Una expresión puede contener los siguientes especificadores de formato:

📖 Sintaxis:

Python sintaxis 
{expresión : [relleno][alineación][signo][ancho][.precisión][tipo]}

💻 Ejemplo: Relleno, alineación y ancho

Python ejemplo 
n = 42
print(f"{n:10}")     # '        42'  → derecha (default)
print(f"{n:<10}")    # '42        '  → izquierda
print(f"{n:^10}")    # '    42    '  → centrado
print(f"{n:*^10}")   # '****42****'  → centrado con relleno '*'
print(f"{n:0>10}")   # '0000000042'  → derecha con relleno '0'

pi = 3.14159
print(f"{pi:10}")      # '   3.14159'   → derecha (default)
print(f"{pi:<10}")     # '3.14159   '  → izquierda
print(f"{pi:^10}")     # ' 3.14159  '  → centrado
print(f"{pi:*^10}")    # '*3.14159**'  → centrado con relleno '*'
print(f"{pi:0^10.2f}") # '00003.1400'  → centrado, 2 decimales, relleno '0'

nombre = "Ana"
print(f"{nombre:<10}")   # 'Ana       '  → alineado a la izquierda (default)

🏷️ Especificadores dinámicos

Cualquier especificador de formato puede ser dinámico. Sin embargo en la práctica el uso dinámico se limita casi siempre al ancho y la precisión, por dos razones:

  • Son los únicos que cambian frecuentemente en tiempo de ejecución, por ejemplo al formatear columnas de una tabla cuyo ancho depende de los datos.
  • Hacer dinámico el tipo o el relleno es poco común y reduce la legibilidad del código, por lo que si el tipo cambia, generalmente es más claro usar un if en lugar de un especificador dinámico.

💻 Ejemplo:

Python ejemplo 
pi = 3.14159
ancho = 10
decimales = 3

print(f"{pi:{ancho}.{decimales}f}")
salida 
     3.142

Type Hints

Anotaciones especiales

En Python, una sugerencia de tipo (type hint) es una construcción sintáctica que permite indicar los tipos de datos esperados de las variables , los argumentos de las funciones y los valores de retorno. Proporcionan una forma de mejorar la mantenibilidad del código al declarar explícitamente el tipo de datos de las variables, los argumentos y los valores de retorno. Sintácticamente, las sugerencias de tipo son una forma de anotación.

Python no impone sugerencias de tipo en tiempo de ejecución , pero los verificadores de tipos estáticos , como mypy , pueden usarlas para detectar posibles errores de tipo en tu código antes de ejecutarlo.

Al usar sugerencias de tipo, también creas código autodocumentado, lo que facilita que tanto tú como otros comprendan cómo usar correctamente las funciones y las clases.

📖 Sintaxis:

Python sintaxis 
nombre_variable: Tipo = valor

💻 Ejemplo:

Python ejemplo 
edad: int = 25
nombre: str = "Ana"
promedio: float = 8.5
activo: bool = True

# También puedes anotar la variable sin asignarle un valor todavía:
estatura: float
estatura = 1.65
💡 Importante:

Python nunca lanza un error en tiempo de ejecución por violar un type hint. Esto funciona sin problema (aunque un verificador de tipos se quejaría):


Python ejemplo 
numero: int
numero = 1.78
print(numero)
salida 
1.78
