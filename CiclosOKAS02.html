¿Qué son las estructuras de iteración?

La base de cualquier algoritmo repetitivo en Python

Las estructuras de iteración (o bucles) permiten ejecutar un bloque de código múltiples veces. Python ofrece dos tipos principales: for (para secuencias conocidas) y while (para condiciones arbitrarias). Además, contamos con palabras clave que modifican el flujo: break y continue, más la cláusula especial else.

💡 Dato importante:

En Python, los bloques de código se definen por indentación (4 espacios por convención), no con llaves {}.

💡 Dato importante:

Un bloque for o while en Python no es una unidad de ámbito (scope) propio. Esto significa que si le asignas un valor a una variable dentro de cualquiera de estos bloques, esa variable sigue perteneciendo al scope que la contiene (la función, el módulo, etc.), y puedes usarla después del bloque, siempre que el bloque se haya ejecutado.

🔁

El ciclo for

Itera sobre cualquier objeto iterable de Python

El ciclo for se utiliza para repetir un bloque de instrucciones mientras se recorren los elementos de un objeto iterable.

📖 Sintaxis

La estructura básica de un bucle for en Python:

Python sintaxis 
for variable in iterable:
	# Bloque de Código

donde:

  • variable: va almacenando, en cada repetición, el elemento que se está recorriendo.
  • iterable: es un objeto que contiene o proporciona una secuencia de elementos que pueden recorrerse
  • El bloque de código va indentado (normalmente 4 espacios).

💡 Tip: Cómo saber si algo es iterable

Anteponer un asterisco * al objeto dentro de unos corchetes [] dentro de un print():


Python ejemplo 
# Si funciona sin error -> ES ITERABLE
print([*"Hola"] )       # Imprime: ['H', 'o', 'l', 'a']
print([*range(3)])      # Imprime: [0, 1, 2]
print(*[1, 2])          # Imprime: 1 2

# Si lanza TypeError -> NO ES ITERABLE
print([*123])           # TypeError: 'int' object is not iterable

🔁 1. for con range()

Una de las formas más utilizadas de for es junto con la función range().

💻 range(fin)

Genera números desde 0 hasta fin - 1, de uno en uno.

Python ejemplo 
for i in range(5):
	print(i)
salida 
0
1
2
3
4

💻 range(inicio, fin)

Genera números desde el valor de inicio hasta fin - 1, de uno en uno.

Python ejemplo 
for i in range(3, 8):
	print(i)
salida 
3
4
5
6
7

💻 range(inicio, fin, paso)

Genera números desde el valor de inicio hasta fin - 1, el incremento depende del valor de paso.

Python ejemplo 
for i in range(0, 10, 2): #incrementa el valor de i de 2 en 2
	print(i)
salida 
0
2
4
6
8
💡 Importante:

La función range() no incluye el valor de fin.

🔢 2. Recorre una cadena letra por letra

Una cadena es un iterable, por lo tanto podemos recorrer cada uno de sus caracteres.

Python ejemplo 
nombre = "Python"
	for letra in nombre:
		print(letra)
salida 
P
y
t
h
o
n

🔢 3. for con enumerate()

La función enumerate() se utiliza cuando, además de obtener cada elemento de un iterable, también necesitamos conocer su posición o índice.

Python sintaxis 
for índice, elemento in enumerate(iterable):
	#Bloque de código

El valor inicial de índice es 0.

💻 Ejemplo:

Python ejemplo 
palabra= "Python"

for indice, letra in enumerate(palabra):
	print(f"{indice}: {letra}")
salida 
0: P
1: y
2: t
3: h
4: o
5: n

💻 Ejemplo:

Cambia el valor inicial de enumerate() con start

Python ejemplo 
palabra= "Python"

for indice, letra in enumerate(palabra, start = 1):
	print(f"{indice}: {letra}")
salida 
1: P
2: y
3: t
4: h
5: o
6: n

También se puede omitir la palabra start:


Python ejemplo 
palabra= "Python"

for indice, letra in enumerate(palabra, 1):
	print(f"{indice}: {letra}")
salida 
1: P
2: y
3: t
4: h
5: o
6: n

El ciclo while

Repite mientras la condición sea verdadera

El while es un ciclo que repite un bloque de código mientras una condición sea verdadera. A diferencia del for (que recorre un iterable), el while no sabe de antemano cuántas veces se va a repetir: simplemente sigue ejecutándose hasta que la condición se vuelve falsa.

📖 Sintaxis

La estructura básica de un bucle while en Python:

Python sintaxis 
while condición:
	# Bloque de Código que se ejecuta si la condición es True

El bloque de código va indentado (normalmente 4 espacios).

⚠️ Precaución:

Si la condición del while nunca se vuelve False, tendrás un bucle infinito. Siempre asegúrate de que la variable de control cambie en cada iteración.

💻 Ejemplo:

Python ejemplo 
i = 0
while i < 5:
	print(i)
	i += 1
salida 
0
1
2
3
4

⚠️ Cuidado con los bucles infinitos:

Si la condición nunca se vuelve falsa, el ciclo nunca termina. Es uno de los errores más comunes con while.

Python ejemplo 
i = 0
while i < 5:
	print(i)
	# Faltó: i += 1
salida 
0
1
2
3
4

Regla de oro: dentro del while, debe haber algo que eventualmente haga que la condición se vuelva falsa.

La sentencia break

Interrumpe el ciclo de forma inmediata

break es una instrucción de control de flujo que termina inmediatamente el ciclo (for o while) en el que se encuentra, sin importar si la condición del ciclo seguía siendo verdadera o si quedaban elementos por recorrer. Una vez ejecutado, el programa continúa con la primera línea de código después del ciclo.

📖 Sintaxis: con for

Python sintaxis 
for variable in iterable:
	if condición:
		break
	# código

📖 Sintaxis: con while

Python sintaxis 
while condición:
	if otra_condición:
		break
	# código

💻 Ejemplo con for:

Python ejemplo 
for i in range(5):
	if i == 3: # si i es igual a 3, sale del ciclo
		break
	print(i)
salida 
0
1
2

💻 Ejemplo con while:

Python ejemplo 
n = 0
while n < 10:
	if n == 4: # si i es igual a 3, sale del ciclo
		break
	print(n)
	n += 1
salida 
0
1
2
3
⏭️

La sentencia continue

Salta a la siguiente iteración sin finalizar el ciclo

continue continue es una instrucción de control de flujo que salta el resto del código dentro del ciclo actual y pasa directamente a la siguiente iteración, sin ejecutar las líneas que quedan después de él en esa vuelta.
A diferencia de break, continue no termina el ciclo, solo se salta la iteración actual y sigue con la siguiente.

📖 Sintaxis: con for

Python sintaxis 
for variable in iterable:
	if condición:
		continue
	# código que se salta cuando se cumple la condición

📖 Sintaxis: con while

Python sintaxis 
while condición:
	if otra_condición:
		continue
	# código que se salta cuando se cumple otra_condición

💻 Ejemplo con for:

Python ejemplo 
for i in range(5):
	if i == 3:
		continue
	print(i)
salida 
0
1
2
4

💻 Ejemplo con while:

Python ejemplo 
n = 0
while n < 6:
	n += 1
	if n % 2 == 0:
		continue
	print(n)
salida 
1
3
5

La cláusula else en ciclos

Se ejecuta solo si el ciclo no se interrumpio con break

Python permite añadir un bloque else al final de un ciclo for o while. Este bloque se ejecuta únicamente si el ciclo terminó de forma natural, es decir, sin haber sido interrumpido por un break. Si el ciclo fue interrumpido con break, el else se salta y no se ejecuta.

🧠 Regla mnemotécnica:

Piensa en el else como "si no se encontró nada" — perfecto para búsquedas donde quieres saber si terminaste sin éxito.

📖 Sintaxis: con for

Python sintaxis 
for variable in iterable:
	# código
else:
	# se ejecuta si el ciclo terminó sin break

📖 Sintaxis: con while

Python sintaxis 
while condición:
	# código
else:
	# se ejecuta si el ciclo terminó sin break

💻 Ejemplo con for:

Python ejemplo 
numero = 7

for i in range(2, numero):
	if numero % i == 0:
		print(f"{numero} NO es primo (divisible por {i})")
		break
else:
	print(f"{n} ES primo ✓" )
salida 
7 ES primo ✓

💻 Ejemplo con while:

Python ejemplo 
intentos = 3

while intentos > 0:
	clave = input("Ingresa la clave: ")
	if clave == "1234":
		print("✅ Acceso concedido.")
		break  # Interrumpe el bucle
	
	intentos -= 1
	print(f"Clave incorrecta. Te quedan {intentos} intentos.")
else:
	# Solo se ejecuta si los intentos llegaron a 0 (la condición 'intentos > 0' se volvió False)
	print("🔒 Cuenta bloqueada por demasiados intentos fallidos.")
salida 
Ingresa la clave: 123
Clave incorrecta. Te quedan 2 intentos.
Ingresa la clave: 321
Clave incorrecta. Te quedan 1 intentos.
Ingresa la clave: 159
Clave incorrecta. Te quedan 0 intentos.
🔒 Cuenta bloqueada por demasiados intentos fallidos.
